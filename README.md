Agroforte: Futuro Sustentável — Concurso Agrinho 2026

O projeto é uma aplicação web interativa desenvolvida no formato de "Livro 3D" digital para o Concurso Agrinho 2026. O objetivo principal do projeto é ensinar, de forma lúdica e gamificada, como o agronegócio moderno e a preservação do meio ambiente caminham juntos.

Guiado pelo mascote "Sementinha", o usuário navega por páginas repletas de animações e conteúdos educativos. O sistema conta com recursos visuais avançados, incluindo uma barra de progresso em tempo real (Índice de Sustentabilidade), mapa do Brasil clicável e pontos flutuantes que revelam modais de curiosidades sobre as tecnologias no campo. No último capítulo, a tomada de decisão do usuário altera as cores e o cenário da aplicação, gerando um final reflexivo com a animação do crescimento de uma árvore.

Desenvolvido com foco em alta performance e responsividade para dispositivos móveis, o projeto utiliza exclusivamente tecnologias nativas: HTML5 para a estrutura semântica, CSS3 para os gradientes e animações customizadas, e JavaScript para o controle de telas e interatividade. O resultado é uma ferramenta pedagógica poderosa que une conscientização ambiental e tecnologia.# AGRINHO-2026-EDINA
